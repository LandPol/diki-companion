# Diki Companion

**A Chrome extension that enhances the Diki.pl dictionary experience.**

## About the Project

Diki Companion started as a simple idea: creating a **dark theme for Diki.pl** to make using the dictionary more comfortable.

During development, new ideas and improvements emerged, gradually turning the project into a more comprehensive vocabulary learning tool.

The entire project, from the initial idea to the working solution, was developed in just **two days** with the help of AI.

## Features

- **Dark Mode** – Toggleable dark theme with saved preferences.
- **Ad Blocking** – Hides promotional banners, pop-ups, and advertising sections on Diki.pl.
- **Automatic Vocabulary Collection** – Saves English words, Polish translations, and example sentences directly from dictionary results.
- **Vocabulary Manager** – Add, search, edit, and delete saved entries.
- **Tags** – Organize vocabulary into custom categories.
- **Export Options** – Export vocabulary to CSV, TXT, JSON, and Anki formats.
- **Backup & Restore** – Create and restore JSON backups of your vocabulary.
- **Language Selection** – Switch the extension interface between English and Polish.

Vocabulary is stored in a consistent **English → Polish** format, regardless of the direction of the original dictionary search.

## Tech Stack

- HTML5, CSS3, JavaScript
- Chrome Extensions API (Manifest V3)
- FileSaver.js, JSZip, Genanki, SQL.js

## Installation

1. Clone or download this repository.
2. Open `chrome://extensions/` in Google Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
